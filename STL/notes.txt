LOCAL ARRAY vs GLOBAL ARRAY (C++)

Why can local arrays usually be up to 10^5–10^6 elements, while global arrays can often be up to 10^7 elements?

Reason:
The difference is because they are stored in different memory regions.

----------------------------------------------------
1. Local Arrays (Stack Memory)
----------------------------------------------------

Example:

int main() {
    int arr[100000];
}

- Local arrays are stored on the STACK.
- The stack has a small fixed size.
- Typical stack size:
    • Linux: ~8 MB
    • Windows: ~1 MB

Memory Calculation:

For int:
1 int = 4 bytes

arr[100000]
= 100000 × 4
≈ 0.4 MB

arr[1000000]
= 1000000 × 4
≈ 4 MB

arr[10000000]
= 10000000 × 4
≈ 40 MB

A 40 MB local array exceeds the stack limit, causing a Stack Overflow (Segmentation Fault).

----------------------------------------------------
2. Global Arrays (Data/BSS Segment)
----------------------------------------------------

Example:

int arr[10000000];

int main() {

}

- Global arrays are stored in the Data/BSS segment.
- This memory region is much larger than the stack.
- It is mainly limited by the program's memory limit and available RAM.

Example:

arr[10000000]
= 10000000 × 4
≈ 40 MB

40 MB is generally acceptable for a global array.

----------------------------------------------------
3. Heap Memory
----------------------------------------------------

Large arrays can also be allocated on the heap.

Example:

vector<int> arr(10000000);

or

int* arr = new int[10000000];

Heap memory is much larger than the stack.

----------------------------------------------------
4. Memory Layout
----------------------------------------------------

High Address
-------------------------
| Stack              |  ← Local variables
-------------------------
| Heap               |  ← new, malloc, vector
-------------------------
| Data/BSS           |  ← Global & static variables
-------------------------
| Code               |
-------------------------
Low Address

----------------------------------------------------
5. Competitive Programming Rule
----------------------------------------------------

int arr[1e5];   → Local or Global
int arr[1e6];   → Usually okay locally on many systems, but Global is safer
int arr[1e7];   → Global or Heap
int arr[1e8];   → Heap only (if memory limit allows)

----------------------------------------------------
Key Points
----------------------------------------------------

• Local arrays are stored on the Stack.
• Global arrays are stored in the Data/BSS segment.
• Heap memory is used by vector, new, and malloc.
• Stack memory is small (≈1–8 MB), so very large local arrays cause Stack Overflow.
• Global and Heap memory are much larger, making them suitable for large arrays.
